# Max Sum Pairing Diff Less Than 'k'

## Problem Statement

Given an array arr[] of positive integers and a number k, Return maximum pair sum with the following conditions on the pairs.

Pair difference should be less than k.

Pairs should be disjoint. For example if indices (x, y) is a result pair, then neither x nor y should appear in any other result pair.

If no valid pairs can be formed, return 0.
