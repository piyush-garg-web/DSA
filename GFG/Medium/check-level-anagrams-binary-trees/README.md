# Check Level Anagrams in Binary Trees

## Problem Statement

Given the roots of two binary trees root1 and root2, check whether the nodes at every corresponding level of the two trees are anagrams of each other. Two levels are considered anagrams if they contain the same node values with the same frequencies, irrespective of their order.
