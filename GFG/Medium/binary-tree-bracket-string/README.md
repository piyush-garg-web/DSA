# Binary Tree Bracket String

## Problem Statement

Given a string s representing a binary tree, construct the tree and return the root node.

The string is formatted as follows: it contains an integer, followed by zero, one, or two pairs of parentheses.

The integer represents the value of the current node.

If no children, the integer is not followed by any parentheses.

If two children, two pairs of parentheses follow - the first recursively represents the left, and the second recursively represents the right subtree.

If only left child, then the next bracket has left subtree.

If only right child, then there are two brackets, one empty bracket to represent a left child and next bracket has right subtree.

Note: The driver code will print the inorder traversal of the constructed tree as the final output.
