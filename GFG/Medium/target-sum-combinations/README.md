# Target Sum Combinations

## Problem Statement

Given an array arr[] of distinct integers and a target, find all unique combinations in the array where the sum is equal to target. The same number may be chosen from the array any number of times to make target.

Note: You can return your answer in any order, but the driver code will print the combinations in sorted order only.
