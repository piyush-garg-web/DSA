# Dupliocate Subtree Check

## Problem Statement

Given the root of a binary tree, determine whether the tree contains any duplicate subtree of size two or more. Two subtrees are considered duplicates if they have the same structure and identical node values.

Return true if such a duplicate subtree exists; otherwise, return false.

Note: Subtrees consisting of only a single leaf node are not considered duplicate subtrees.
